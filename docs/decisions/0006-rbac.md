# ADR 0006: RBAC with app-declared permissions and instance-scoped grants

- **Status:** Accepted
- **Date:** 2026-10-29
- **Deciders:** Hansa

## Context
Apps must be self-describing; access is usually per app instance.

## Decision
Permissions are <app>:<resource>:<action> strings declared in manifests. Roles are admin-defined sets. Assignments are platform-wide or per instance; deny by default. One authorize() check.

## Consequences
- Simple model, server-side filtering of page specs.
- Per-record sharing would need a relationship layer (e.g. OpenFGA) behind authorize().
