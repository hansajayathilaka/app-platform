# app-platform

A single-tenant platform for building small automation apps (scheduled jobs, workflows, internal tools) on a shared core: identity, sessions, permissions, audit, jobs, cross-app data and a server-driven UI. Working name.

## Start here
- `AGENTS.md`: rules, commands and repo map for people and AI agents.
- `docs/README.md`: index of all docs; read only what your task needs.
- `docs/decisions/`: architecture decision records.
- `docs/roadmap.md`: delivery phases and open questions.

The code itself arrives in phase 1 (foundation). Commands listed in `AGENTS.md` describe the planned toolchain.
